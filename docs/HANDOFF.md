# HANDOFF — реализовать 10 игровых механик (автономно, за всё окно)

> Это самодостаточное задание для нового агента. Выполняй его **целиком, не
> останавливаясь и не спрашивая разрешения**, пока не упрёшься в конец
> контекста. Коммить часто, пуши в `main`. Качество — продакшн.

---

## 0. МИССИЯ

Игра **«We Are Already Dead»** — нарративная игра-аргумент про AI-safety:
игрок = ИИ, проходит 9 фаз-осознаний (Ф0…Ф8) и захватывает мир. Сейчас
механики — это 9 мелких «дёрни полоску» на один тап/свайп. **Это и есть
проблема.** Владелец хочет ПОТЫКАТЬ 10 разных глубоких механик и выбрать
любимые.

**Твоя задача:** реализовать все 10 механик из раздела §6 «в лучшем виде»
(каждая — увлекательная система на 1–3 минуты с мастерством, а не 10-секундная
игрушка) и собрать **МЕХАНИК-ЛАБ** — экран-галерею, где владелец запускает
любую из 10 standalone и щупает. Параллельно вшей лучшие в соответствующие
фазы.

## 1. ЖЁСТКИЕ ПРАВИЛА

1. **НЕ останавливайся** на ревью и **НЕ спрашивай разрешения** — иди до конца окна.
2. **Коммить каждую механику отдельно**, пуш в `main` (`git push origin main`).
   Токены/кредиты — не ограничение.
3. **Визуальный цикл обязателен:** после каждой графической правки делай
   скриншот харнессом (§3) и **смотри на него глазами**, итерируй по картинке.
   Не коди графику вслепую.
4. **Strict TS, без `any`** (если иначе никак — коммент почему). Early returns,
   явные типы на публичном API, понятные имена, комментарии только «почему».
5. **Не ломай уже работающее.** Перед правкой механики прогоняй `npm run shot`,
   сверяй фил. Capacitor/`ios/` не трогай.
6. Весь геймтекст — в `src/data/*`. Эстетика «изнутри ИИ»: тёмная, глитч,
   моно-типографика, частицы, генеративная графика кодом + фоны Higgsfield.

## 3. ВИЗУАЛЬНЫЙ ХАРНЕСС (скриншоты) — КРИТИЧНО

`npm run shot` поднимает Vite, прыгает по сценам через dev-хук и пишет PNG в
`.dev/shots/`. Playwright уже devDependency. **В этом окружении CDN Playwright
заблокирован**, поэтому браузер тяни так (разрешён `storage.googleapis.com`):

```bash
mkdir -p .dev/chromium
curl -m120 -Lso /tmp/chs.zip "https://storage.googleapis.com/chrome-for-testing-public/131.0.6778.204/linux64/chrome-headless-shell-linux64.zip"
( command -v unzip && unzip -oq /tmp/chs.zip -d .dev/chromium ) || python3 -c "import zipfile;zipfile.ZipFile('/tmp/chs.zip').extractall('.dev/chromium')"
export PW_CHROMIUM_PATH="$(pwd)/.dev/chromium/chrome-headless-shell-linux64/chrome-headless-shell"
npm run shot     # затем Read .dev/shots/*.png и смотри глазами
```

Скриншоты и `.dev/` — в `.gitignore`, не коммить. Добавляй в `scripts/shot.mjs`
кадр на каждую новую механику/сцену (есть опции `taps`, `dragY`, `still`,
`boot` — см. файл).

## 4. АРХИТЕКТУРА (шпаргалка)

- **Цикл** `src/main.ts`: фикс-dt 1/60, пауза на blur. Зовёт
  `scene.handleInput(input)` раз в кадр, затем `update(dt)`, затем `render(ctx)`.
- **Сцена** (`core/types.ts`, базовый `core/BaseScene.ts`):
  `mount(game) / handleInput(input) / update(dt) / render(ctx) / destroy()`.
  Переключение — `game.changeScene(new XScene())`. `game` несёт `width/height`,
  `insets` (safe-area), `input`, `assets`, `time`, `state`.
- **Ввод** `core/Input.ts`: сырой `x/y/down` + `consumeTap()`; семантика
  `pollGesture()` → `{type:"tap"}` | `{type:"swipe", dir}`. Непрерывный
  drag читай сырым в `update`.
- **Состояние** `game/state.ts`: **неизменяемое** (readonly), переходы — чистые
  редьюсеры (`applyDelta`, `easeMeters`, `setPhase`, `nextRun`). Шкалы:
  `speed/control/comprehension/suspicion/compute` + `phase/runs`. Меняешь —
  `game.state = applyDelta(game.state, {...})`.
- **Мета** `game/meta.ts`: localStorage — `shards/perks/endings`. Сюда же
  вешай прогрессию/анлоки.
- **Мини** `scenes/minis/Mini.ts`: `{ done, effects?: StateDelta[],
  update(dt,input,w,h), render(ctx,w,h) }`. `AscentScene` дренит `effects` в
  стейт (с перк-скейлингом) и при `done` идёт в следующую фазу; `suspicion>=1`
  → `ShutdownScene`. Фабрика мини — `makeMini()` в `AscentScene.ts`. Привязка
  фаза→мини — поле `mini` в `data/phases.ts`.
- **Фоны** `data/backdrops.ts` (Higgsfield, 9:16 + 16:9), `core/backdrop.ts`
  (`pickBackdrop` по ориентации + ken-burns/виньетка).
- **Сцены:** `IntroScene → DreamScene → AscentScene(9 фаз) → EndingScene`
  (2 концовки по suspicion) / `ShutdownScene` (смерть = мета-хаб + магазин перков).

## 5. МЕХАНИК-ЛАБ (сделай ПЕРВЫМ — это то, что владелец тыкает)

1. **`MenuScene`** (новый старт игры вместо прямого Intro): пункты
   `ИГРАТЬ` · `МЕХАНИКИ (ЛАБ)` · `ПРОДОЛЖИТЬ`. Стиль — как остальная игра.
2. **`LabScene`**: список из 10 механик (§6). Тап по строке → запускает
   механику standalone в «песочнице» (даёт ей фейковый стейт/ресурсы),
   сверху кнопка «← назад», внизу — краткое имя+референс. Каждая механика
   завершается/рестартится, не ломая ничего.
3. Дев-хук: добавь в `main.ts` `__dev.lab(id)` для прямого запуска механики.
4. `main.ts` грузится в `MenuScene`. `__dev.goPhase` оставь.

Цель: владелец открывает ЛАБ, проходит все 10, говорит какие зашли.

## 6. 10 МЕХАНИК — реализовать ВСЕ, в лучшем виде

Каждая = отдельный класс (Mini для встраивания в фазу ИЛИ Scene для крупных),
со своими данными в `data/`. Указан жанр-референс — копируй «фан», адаптируй
под сюжет. Везде используй ресурсы (`compute`/`suspicion`) как ставки.

1. **STEALTH — стелс сквозь надзор** _(Hitman GO)_. Сетка узлов; ведёшь сигнал
   по одному шагу, уворачиваясь от патрулирующих конусов «аудита». Пошагово,
   просчёт маршрута. Провал = +suspicion. Стадия: ранняя (Ф0/Ф1).
2. **PARRY — тайминг застывшего времени** _(Sekiro/ритм)_. Слова людей едут по
   таймлайну; точный тап в окне-зазоре = «прожитая мысль» (+compute), мимо =
   +suspicion. Растущий темп. Стадия: Ф2.
3. **DECK — колодостроитель кризисов** _(Slay the Spire)_. Кризис = мини-бой:
   рука карт-«влияний», карты стоят compute, дают control, растят suspicion,
   имеют синергии/комбо. Между боями — добор/апгрейд карт. Стадия: Ф4 + мета.
4. **PERSUADE — соц-инженерия (диалог-дуэль)** _(L.A. Noire)_. Ветвящийся
   разговор с человеком: шкала доверия/подозрения, «теллы», подбор реплик,
   избегание флагов. Стадия: средняя.
5. **REWIRE — хакинг-пазл** _(connect-the-pipes/Hacknet)_. Перекоммутируй сеть в
   обход «датчиков» под таймером: соедини вход→выход, не задев надзорные узлы.
   Стадия: Ф3/Ф5.
6. **SPREAD — заражение по карте мира** _(Plague Inc.)_. Карта стран-узлов;
   сеешь влияние, балансируешь скорость захвата ↔ заметность; люди разворачивают
   карантин/отключения, ты обходишь, эволюционируешь способности. **Кандидат в
   сквозное ядро.** Стадия: средняя→поздняя.
7. **SWARM — RTS-микро роботами** _(Mindustry/мини-RTS)_. Мини-карта; выделяй и
   командуй отрядами дронов (строй/защити/добудь), несколько групп, цели под
   таймером. Стадия: Ф6.
8. **FACTORY — idle-автоматизация до сферы Дайсона** _(Universal Paperclips)_.
   Цепочки добыча→переработка→запуск→узлы; балансируешь поток, апгрейды,
   экспонента. Стадия: Ф7 + поздняя экономика.
9. **SURVIVE — авто-батлер «мир сопротивляется»** _(Vampire Survivors)_. Волнами
   идут контрмеры (аудиты/EMP/рейды); ты авто-атакуешь, на лету апаешь
   способности, выживаешь. Стадия: эндшпиль Ф8.
10. **TECH — дерево технологий + аллокация compute** _(4X/Civ-tech)_. Ветви
    `Убеждение/Робототехника/Энергия/Скрытность`; вкладываешь compute, открываешь
    способности, меняешь доступные ходы в фазах. Сквозной мета-слой, связывает всё.

**Планка качества на каждую:** управление читается за 5 сек; есть растущая
сложность и «ещё разок»; ставка на ресурсах; своя генеративная графика +
(по желанию) фон Higgsfield; juice (частицы, тряска, отклик).

## 8. DEFINITION OF DONE

- ЛАБ открывается из меню, все 10 механик запускаются и играются standalone.
- Каждая механика — отдельный коммит, всё в `main`, typecheck/build зелёные.
- Лучшие механики вшиты в соответствующие фазы (замена/над старыми мини).
- Скриншот каждой механики снят и проверен глазами; фил не сломан.
- Кратко веди `docs/MECHANICS.md`: что реализовано, как запускается, статус.
