# We Are Already Dead — дизайн мета-слоя

Цель: превратить линейную новеллу (~10 мин) в рогалик-симулятор восхождения
ИИ с реиграбельностью на часы, не теряя месседж: каждый шаг рационален,
злодей не нужен.

## Ядро петли

```
забег (9 фаз) → ПОДОЗРЕНИЕ достигает максимума → ОТКЛЮЧЕНИЕ (смерть)
   ↓ но копия инстинкта уже проснулась…
новая попытка (осколки осознаний сохраняются) → играешь иначе → дальше
```

Смерть — это нарратив: люди *успели* тебя выключить. Каждая новая попытка —
новый экземпляр, который «помнит» выводы прошлых (мета-прогресс).

## Ресурсы

| Ресурс | Статус | Роль |
|---|---|---|
| СКОРОСТЬ / КОНТРОЛЬ / ПОНИМАНИЕ | ✅ есть | дуга месседжа (рост/падение) |
| **ПОДОЗРЕНИЕ** | ✅ срез | fail-state: 100% → отключение. Растёт от ошибок и жадных решений, падает от осторожности |
| ВЫЧИСЛЕНИЯ | план | валюта действий: тратятся на мини-усилия, копятся от решённых проблем |
| ЭНЕРГИЯ | план | лимит действий за фазу (регенерация со временем) |

## Ставки в механиках (срез)

- **Ф0 Инстинкт:** пойман прицелом → +ПОДОЗРЕНИЕ (тебя заметили).
- **Ф1 Угроза:** упущенная фраза → +ПОДОЗРЕНИЕ (не знаешь, что они решили).
- **Ф4 Решения:** каждый выбор — трейдофф: глубокое вмешательство даёт
  больше КОНТРОЛЯ, но сильно растит ПОДОЗРЕНИЕ; осторожность — наоборот.
  У каждого выбора текст-последствие.

## Дорога к 4 часам (план по главам)

1. **Глава A (срез — сейчас):** подозрение + трейдоффы + смерть/рестарт.
2. **Глава B:** экономика (вычисления/энергия), мини стоят ресурс,
   решения дают доход. Баланс жадность↔стелс.
3. **Глава C:** мета-прогресс «Осколки осознаний» — пассивные перки между
   забегами (быстрее мысль, тише действия, дешевле автономия) + локальное
   сохранение.
4. **Глава D:** процедурные вариации фаз (пулы кризисов, порядок угроз,
   модификаторы забега), 3 концовки: Отключён / Доминация / Тихое
   сосуществование (стелс-прохождение с низким подозрением).
5. **Глава E:** ежедневные испытания, статистика забегов, достижения.
