# МЕХАНИК-ЛАБ — статус

Игра грузится в **MenuScene**: `ИГРАТЬ` (полный нарратив) · `МЕХАНИКИ · ЛАБ`
(галерея прототипов) · `ПРОДОЛЖИТЬ` (сразу в восхождение). Лаб открывает любую
механику standalone в песочнице (`LabRunScene`): фейковый кошелёк 60 ВЫЧ,
своя шкала подозрения (1.0 = «ОБНАРУЖЕН»), отчёт по итогам цикла, рестарт.

Запуск: `npm run dev`, в консоли `__dev.lab("stealth")` / `__dev.goLab()` /
`__dev.goPhase(n)`. Скриншоты всех механик: `npm run shot` → `.dev/shots/`.

## Архитектура

- Каждая механика — класс `Mini` в `src/mechanics/*` + данные в `src/data/*`.
- `MechEnv` (`mechanics/types.ts`) — что механика видит у хозяина: живые
  `getCompute()/getSuspicion()`, `runs`, `topY`. Один и тот же код играется в
  лабе и внутри фазы (`AscentScene` ↔ `LabRunScene`).
- Реестр `mechanics/registry.ts`: id → фабрика; лаб и фазы берут отсюда.
- Общий джус: `mechanics/fx.ts` (частицы, всплывающий текст, тряска),
  `mechanics/util.ts` (палитра, roundRect, hint, Pointer).
- Ввод: латченые `consumeTap()` (срабатывает по нажатию) и `pollGesture()`
  (тап/свайп по отпусканию) — устойчиво к одно-кадровым кликам; сцены
  забирают только свой хром (`Input.peekTap`).
- Ставки везде настоящие: ВЫЧ тратятся из кошелька рана, подозрение копится
  в шкалу смерти; провалы механик — это suspicion, не game over экраны.

## Балансовые прогоны

- `stealth`: dev-валидатор (BFS по (узел, фаза патрулей, маска осколков))
  печатает в консоль минимальные ходы; «непроходим» = console.warn.
- `spread`: симуляция (без способностей — поражение на ~82% мира;
  шифрование переворачивает гонку; победа ~75–110 с).
- `factory`: жадный бот ~3.5 мин до 100% сферы; живой игрок быстрее.
