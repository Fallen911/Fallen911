# Аудит и роадмап (11.06)

## iOS — статус адаптации

Сделано кодом (уже в `main`):
- `viewport-fit=cover`, safe-area-инсеты во всех сценах, `apple-mobile-web-app-*` меты, статус-бар black-translucent.
- Иконки приложения: `public/icons/` (1024/512/180/64, генерятся `node scripts/make-icon.mjs`), `manifest.webmanifest` (fullscreen, portrait), favicon/apple-touch-icon в `index.html` — «На экран Домой» даёт полноэкранное приложение.
- Канвас: `alpha:false, desynchronized:true` (без альфа-композитинга со страницей, меньше латентность), DPR cap 2.
- Звук: WebAudio просыпается на каждый pointerdown и при возврате из app-switcher (visibilitychange) — иначе iOS глушит контекст.
- Жесты: `touch-action:none`, `user-select:none`, `-webkit-touch-callout:none`, без double-tap-zoom.
- Пауза сим-цикла на blur/hidden ✓ (батарея).
- Capacitor-конфиг готов: appId/appName/тёмный фон/contentInset never.

Требует Мака (ограничение Apple, по 5 минут каждый шаг):
1. `node scripts/fetch-art.mjs` — скачает все фоны в `public/bg/` и перепишет `data/backdrops.ts` на локальные пути (CDN из песочницы недоступен — 403). Без этого офлайн-арт не работает. Закоммитить бинарники.
2. `npm run ios:add` (один раз) → `npm run ios` → в Xcode: подставить Team, иконку из `public/icons/icon-1024.png` в Asset Catalog, ▶ на устройство.
3. Опционально: `@capacitor/haptics` для вибро-отклика (см. роадмап ниже).

## Безопасность — выводы аудита

- **Зависимости**: 2 moderate (esbuild→vite, GHSA-67mh-4wv8-2f99) — уязвим только **dev-сервер**, в собранное приложение код не попадает. Лечится мажорным апгрейдом Vite 5→7; делать осознанно, не `--force`. Риск для прода: нулевой.
- **CSP**: в продакшн-сборку инжектится Content-Security-Policy (vite-плагин в `vite.config.ts`): `script-src 'self'`, `object-src 'none'`, img только self/data/арт-CDN. В dev не применяется (HMR). После локализации артов можно убрать CDN из img-src.
- **Поверхность**: нет eval/Function, нет пользовательского ввода в DOM (innerHTML только со статикой в неиспользуемом overlay), нет секретов в репо, сетевых запросов кроме картинок нет, `__dev`-хуки вырезаются из прод-сборки (`import.meta.env.DEV`).
- **Данные игрока**: только localStorage (мета/туториалы/звук) — не PII.

## Оптимизация — статус

- Бандл: 183 KB / 66 KB gzip — отлично для игры; код-сплит не нужен.
- Рендер: один canvas, без DOM в кадре; фиксированный dt 1/60; объектные пулы в частицах (swap-remove); лимиты сущностей (Survive ≤90 врагов, гемы ≤120).
- Возможные следующие шаги (по необходимости, не сейчас): offscreen-кэш статичных слоёв (графикула Spread), `will-read-frequently=false` по умолчанию ✓, дроссель render до 30fps в idle-сценах для батареи.

## Геймдизайн-разбор: что сыро и что докрутить

1. ✅ Карта маршрута: развилки на входе в Ф3 и Ф6 («ТИХИЙ/ГРОМКИЙ ПУТЬ», `data/forks.ts`) — модификаторы подозрения/добычи/контроля до следующей развилки, выбор озвучен, маршрут виден в HUD.
2. ✅ Подозрение кусается: «ВНЕОЧЕРЕДНОЙ АУДИТ» на порогах 0.6 и 0.8 между фазами — одна жёсткая плата rewire (22с); прошёл — −12% подозрения, провозился — свипы платы бьют как обычно.
3. ✅ Синки ВЫЧ: стелс — «ОТКАТ ХОДА −4» после поимки и «ПУТЬ −6» (солвер подсвечивает лучший ход на 3с); убеждение — «ВСКРЫТЬ ОТВЕТ −7» после скана подсвечивает верную реплику.
4. ✅ Смерть учит: экран отключения показывает «ЧТО ТЕБЯ ВЫДАЛО» — топ-3 источника подозрения рана (`game/runlog.ts`).

### P0 — архив (исходная постановка)
1. **Связность рана.** Фазы — последовательность мини-игр; решений «между» ними мало. Добавить **карту маршрута** (à la Slay the Spire): после Ф2 и Ф5 развилка «тихий/громкий путь» — другой набор уровней, модификаторы (тихий: −подозрение, −ВЫЧ; громкий: наоборот). Реиграбельность ×3 малой кровью: данные уже уровневые.
2. **Подозрение должно кусаться.** В сторилайне до 1.0 почти не доходит → между фазами при suspicion>0.6 вызывать «ВНЕОЧЕРЕДНОЙ АУДИТ» — короткое испытание (одна плата rewire на 20с или 3 бита persuade). Провал = −ВЫЧ и +suspicion. Появится дыхание угрозы.
3. **Экономика ВЫЧ в профиците.** Сино́ков мало: добавить траты — «ретрай уровня за N ВЫЧ», платный подсказ в stealth (показать решение на 3с), второй СКАН в persuade. Тогда заработок в parry/factory обретает смысл.
4. **Смерть должна учить.** ShutdownScene не говорит, ЧТО спалило. Лог последних 3 событий подозрения («рейд на хаб +22%», «провал директивы +6%») на экране смерти.

### P1 — механики (точечно)
- **parry**: рандомная сборка фраз → захардкодить «хореографию» 2-3 волн (паттерны как ноты), финальная волна — слова распадаются на буквы.
- **persuade**: контент — нужно 8 новых собеседников до лестницы 10 (инвестор, военный, журналистка, ребёнок-вундеркинд…). Я допишу по 6 битов на каждого по отмашке.
- **survive**: рывок по свайпу (i-frames 0.3с, кд 3с) — глубина уворота; босс должен иметь «телеграф» атаки.
- **swarm**: команда «СТОП/ДЕРЖАТЬ» и рамка на удержании пальца (сейчас только свайп); авто-возврат шахтёров при атаке.
- **spread**: способности-ветки (выбор 1 из 2 на каждом пороге вместо магазина) — билдостроение.
- **factory**: престиж («переплавить сферу» → ×множитель со старта) для длинных сессий.
- **stealth**: «золотой путь» бонус — пройти уровень за минимум ходов солвера (+ВЫЧ ×2); солвер уже знает ответ.
