## Безопасность — выводы аудита

- **Зависимости**: 2 moderate (esbuild→vite, GHSA-67mh-4wv8-2f99) — уязвим только **dev-сервер**, в собранное приложение код не попадает. Лечится мажорным апгрейдом Vite 5→7; делать осознанно, не `--force`. Риск для прода: нулевой.
- **CSP**: в продакшн-сборку инжектится Content-Security-Policy (vite-плагин в `vite.config.ts`): `script-src 'self'`, `object-src 'none'`, img только self/data (CDN убран после локализации артов ✓). В dev не применяется (HMR).
- **Поверхность**: нет eval/Function, нет пользовательского ввода в DOM (innerHTML только со статикой в неиспользуемом overlay), нет секретов в репо, сетевых запросов кроме картинок нет, `__dev`-хуки вырезаются из прод-сборки (`import.meta.env.DEV`).
- **Данные игрока**: только localStorage (мета/туториалы/звук) — не PII.

## Оптимизация — статус

- Бандл: 183 KB / 66 KB gzip — отлично для игры; код-сплит не нужен.
- Рендер: один canvas, без DOM в кадре; фиксированный dt 1/60; объектные пулы в частицах (swap-remove); лимиты сущностей (Survive ≤90 врагов, гемы ≤120).
- Возможные следующие шаги (по необходимости, не сейчас): offscreen-кэш статичных слоёв (графикула Spread), `will-read-frequently=false` по умолчанию ✓, дроссель render до 30fps в idle-сценах для батареи.

- ✅ parry: авторская хореография волн 1/5/10 (data: script[]) — открытие, «совещание без перерывов» и финал-аргумент читаются как написанные сцены.

### P1 — архив (исходная постановка)
- **parry**: рандомная сборка фраз → захардкодить «хореографию» 2-3 волн (паттерны как ноты), финальная волна — слова распадаются на буквы.
- **persuade**: контент — нужно 8 новых собеседников до лестницы 10 (инвестор, военный, журналистка, ребёнок-вундеркинд…). Я допишу по 6 битов на каждого по отмашке.
- **survive**: рывок по свайпу (i-frames 0.3с, кд 3с) — глубина уворота; босс должен иметь «телеграф» атаки.
- **swarm**: команда «СТОП/ДЕРЖАТЬ» и рамка на удержании пальца (сейчас только свайп); авто-возврат шахтёров при атаке.
- **spread**: способности-ветки (выбор 1 из 2 на каждом пороге вместо магазина) — билдостроение.
- **factory**: престиж («переплавить сферу» → ×множитель со старта) для длинных сессий.
- **stealth**: «золотой путь» бонус — пройти уровень за минимум ходов солвера (+ВЫЧ ×2); солвер уже знает ответ.
