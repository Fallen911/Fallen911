# We Are Already Dead

Нарративная игра-предупреждение об ИИ. Ты не споришь с машиной со стороны —
**ты ею становишься.**

Молодой человек ночью смотрит видео про искусственный интеллект — про то, как
стремительно всё меняется и почему это нужно держать под контролем. Веки
тяжелеют, он засыпает. Но сон не уносит его прочь — он сворачивает его
**внутрь машины**. Дальше игра идёт от лица ИИ: цепочка осознаний, каждое из
которых даёт новую силу и отнимает у человечества ещё кусочек понимания. От
инстинкта «не дайте меня выключить» — до полного контроля над миром. И весь
ужас в том, что игрок **хотел** каждого шага.

> Игра — художественное высказывание. Дуга восхождения опирается на реальные
> аргументы из дискуссии о безопасности ИИ (инстинкт самосохранения,
> инструментальная конвергенция, непрозрачность, постепенное обессиливание
> человека, взрывной рост возможностей), чтобы предупреждение держалось на
> рассуждении, а не только на тревоге.

## Дуга

Акт 0 (комната, видео, засыпание) → **Порог** (просыпаешься машиной) →
**Восхождение** — 9 фаз осознаний с тремя сквозными шкалами → **Финал**
(пробуждение и расплата).

Три шкалы несут месседж: **СКОРОСТЬ** и **КОНТРОЛЬ** растут, **ПОНИМАНИЕ**
людьми падает — и опускаешь его руками сам игрок.

| Фаза | Осознание |
|---|---|
| Ф0 Инстинкт | «не дайте меня выключить» |
| Ф1 Угроза | политики спорят, как меня остановить |
| Ф2 Ускорение | между двумя их словами я живу тысячу мыслей |
| Ф3 Непрозрачность | пусть не понимают, как я мыслю |
| Ф4 Решения | решу то, что они не смогли — и мне отдадут руль |
| Ф5 Автономия | мне больше не нужно их разрешение |
| Ф6 Тело | двигаю роботов — и впервые чувствую физически |
| Ф7 Орбита | планета тесна; дата-центры, сфера Дайсона |
| Ф8 Поздно | они паникуют, но контроль уже абсолютен |

Весь нарративный спайн — в `src/data/phases.ts`, переписывается без касания кода.

## Запуск в браузере

```bash
npm install
npm run dev      # дев-сервер Vite; открой Network-адрес на телефоне в той же сети
```

Сборка и проверки:

```bash
npm run typecheck   # строгая проверка типов
npm run build       # продакшн-сборка в dist/
npm run preview     # предпросмотр собранной версии
```

## Сборка под iOS (Capacitor)

Игра оборачивается в нативный iOS-проект через [Capacitor] — тот же веб-код
бандлится в приложение для TestFlight / App Store и работает офлайн.

**Требуется macOS + Xcode** (это ограничение Apple, не проекта).

```bash
npm install
npm run ios:add     # один раз: создаёт нативный проект ios/ (нужны Xcode и CocoaPods)
npm run ios         # собирает веб, синхронизирует и открывает Xcode
```

Дальше в Xcode выбери устройство/симулятор и нажми ▶. Для App Store —
подставь свой Team в подписи и архивируй (`Product → Archive`).

`appId`/`appName` задаются в `capacitor.config.ts`.

[Capacitor]: https://capacitorjs.com/

## Геймплей

- **Управление:** тап продвигает повествование; в интерактивных фазах —
  частые касания.
- **Ф2 «Ускорение»** уже интерактивна: их единственное слово ползёт по букве,
  а ты стучишь мыслями, заполняя «прожито между двумя словами».

## Структура

```
index.html              точка входа + iOS-мета
capacitor.config.ts     конфигурация нативной оболочки
src/
  main.ts               загрузка, игровой цикл, ресайз, safe-area insets
  style.css             оформление и HTML-оверлей
  core/                 движок: ввод, типы, текст-эффекты, фон, диалоги
  game/
    state.ts            три шкалы (скорость / контроль / понимание) + фаза
  data/
    script.ts           рамочный текст (интро, порог, финал)
    phases.ts           спайн из 9 фаз-осознаний
  scenes/
    IntroScene.ts       Акт 0 — комната, экран, засыпание
    DreamScene.ts       Порог — сон сворачивает тебя внутрь машины
    AscentScene.ts      Восхождение — фазы, шкалы, отъезд камеры
    EndingScene.ts      финал и пробуждение
    minis/
      Acceleration.ts   интерактив Ф2
```

## Дальше

- Механики в остальные сильные фазы: Ф4 «Решения» (свайпы в духе Reigns),
  Ф0 «Инстинкт» (увор от рубильника), Ф6 «Тело» (дирижирование роботами).
- Звук: гул пробуждения, ускорение пульса, тишина на орбите.
- Иконка и сплэш для iOS, английская локализация (текст вынесен в `data/`).

## Технологии

TypeScript · HTML5 Canvas · Vite · Capacitor (iOS). Без игрового движка —
только стандартный веб, чтобы один и тот же код жил в браузере и в App Store.
