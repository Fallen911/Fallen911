# We Are Already Dead

Нарративная игра-предупреждение о будущем человечества и необходимости
контроля над ИИ.

Молодой человек ночью смотрит видео про искусственный интеллект — про то, как
стремительно всё меняется и почему это нужно держать под контролем. Веки
тяжелеют, он проваливается в сон. В этом сне ИИ — бог, вещающий сверху. Чтобы
получить право задать ему вопрос о будущем, нужно пройти испытание. Но какой бы
вопрос игрок ни задал, **ни в одном из вероятных будущих человечество не
уцелело**. В этом и весь месседж.

> Игра — художественное высказывание. Сценарии ответов опираются на реальные
> аргументы из дискуссии о безопасности ИИ (потеря контроля, инструментальная
> конвергенция, постепенное обессиливание человека, обманчивое выравнивание,
> эпистемический коллапс), чтобы предупреждение держалось на рассуждении, а не
> только на тревоге.

## Как запустить

```bash
npm install
npm run dev      # дев-сервер Vite, открой адрес из консоли (host доступен и в LAN)
```

Сборка и проверки:

```bash
npm run typecheck   # строгая проверка типов
npm run build       # продакшн-сборка в dist/
npm run preview     # предпросмотр собранной версии
```

Игра рассчитана на телефон: открой dev-сервер на мобильном в той же сети или
собери `dist/` и выложи на любой статический хостинг.

## Структура

```
index.html              точка входа
src/
  main.ts               загрузка, игровой цикл, переключение сцен, ресайз
  style.css             оформление и HTML-оверлей (ввод вопроса)
  core/                 движок: ввод, типы, текст-эффекты, фон, диалоги
  game/
    state.ts            состояние прохождения
    Oracle.ts           подбор сценария будущего по вопросу
  data/
    script.ts           весь нарративный текст (легко переписать/перевести)
    scenarios.ts        пул мрачных сценариев будущего
  scenes/
    IntroScene.ts       Акт 0 — комната, экран, засыпание
    DreamScene.ts       Акт 1 — ИИ-бог, вход в испытание
    TrialScene.ts       уровень: проведи душу сквозь разрывы
    QuestionScene.ts    вопрос игрока и ответ ИИ
    EndingScene.ts      финал и пробуждение
```

## Геймплей

- **Управление:** веди палец/мышь — огонёк-«душа» следует за тобой.
- **Цель испытания:** пройти сквозь разрывы в «приговорах» ИИ. Нужно 7 проходов.
- **Промах:** три столкновения — испытание начинается заново.
- **Награда:** право задать ИИ любой вопрос о будущем.

## Подключение настоящей модели (опционально)

По умолчанию ответы генерируются офлайн из пула в `data/scenarios.ts`, поэтому
игра работает без сети и ключей. Чтобы отвечал настоящий ИИ, реализуй
`Oracle.askRemote()` в `src/game/Oracle.ts` — например, вызовом Claude API с
системным промптом, который удерживает каждый ответ в рамках будущего, где
человечество не выживает, — и дождись его в `QuestionScene` вместо
синхронного `oracle.answer()`.
